# template-bun-cli — DEPRECATED

> ⚠️ **Deprecated.** New CLIs are built on Effect, not oclif.
>
> Use [`template-bun-effect`](https://github.com/yoshintame/template-bun-effect) with its `@effect/cli` recipe instead:
>
> ```sh
> bun create yoshintame/template-bun-effect my-cli
> cd my-cli
> bun add @effect/cli @effect/printer @effect/printer-ansi
> ```
>
> See the CLI recipe in the `template-bun-effect` README. This oclif-based template is no longer maintained; the repository is archived (read-only).
